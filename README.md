# fayd

**f**orget **a**bout **y**our **d**istractions.

A minimal focus timer to help you stay productive.

## Features

- **Focus sessions** with stopwatch or countdown modes
- **Tags** to categorize your work
- **Contribution graph** to visualize your consistency
- **Stats** to track your progress over time
- **Cloud sync** when signed in

## Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS

**Backend:** Node.js, Express, MongoDB, Google OAuth

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
